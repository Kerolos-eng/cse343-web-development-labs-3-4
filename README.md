# CSE343 Web Development — Labs 3 & 4

Two independent, browser-based JavaScript applications for the Lab 3 and Lab 4 tasks.

**GitHub repository:** https://github.com/Kerolos-eng/cse343-web-development-labs-3-4

## Projects

- **Lab 3 — Calculator:** basic arithmetic operations, decimals, sign changes, percentages, keyboard input, clear, and divide-by-zero handling.
- **Lab 4 — To-do list:** add, complete, filter, edit, and delete tasks; clear completed or all tasks; task totals, completion progress, and persistence using `localStorage`.

## Run locally

Open `Lab3/index.html` or `Lab4/index.html` in a current browser. Alternatively, start a local server from the repository root:

```bash
python3 -m http.server 8000
```

Then open `http://localhost:8000/Lab3/` or `http://localhost:8000/Lab4/`.
